Présentation du projet

Le monde de Dytopia est un monde créé par l'imagination d'un être tout-puissant. Ce monde n'existe pas et n'est qu'une illusion.
Le personnage principal et central de ce monde est Nexus MARVIK, l'être le plus puissant sur le plan narratif, capable d'altérer les mondes dans lesquels il est présent, y compris ceux d'autres réalités.
La nation centrale de ce projet est l'Empire Nexuria, une nation indépendante qui cherche à avoir un peuple autonome, puissant et libre.

Le monde n'existe pas et doit être considéré comme quelque chose d'illusoire dans son existence même.

Connexion au terminal

Le terminal est le centre de connexion entre l'utilisateur et les documents. Cette initiative immersive permet de rendre le monde beaucoup plus réel.
L'utilisateur devra donc saisir son identifiant et son mot de passe.

Les identifiants et les mots de passe sont créés uniquement par les membres internes de l'Empire. Aucun identifiant n'est associé à un membre réel.

Liste des commandes

Une fois connecté, vous pourrez saisir des commandes dans le terminal. En voici la liste :

  • list : renvoie la liste des documents disponibles.
  • run {arg1} : ouvre une fenêtre contenant le document indiqué en argument ({arg1}). Cet argument doit correspondre à un document disponible via la commande list.
  • stop : ferme la fenêtre ouverte.

Contribution

Pour ajouter un document relatif au lore, il vous suffit de créer un fork GitHub à partir de ce lien : ici.
Les documents doivent respecter la nomenclature suivante : le nom du fichier doit suivre le format "Document-SUJET-SOUSSUJET2-ETC.md" et son contenu doit être entièrement rédigé en Markdown.
Lorsque vous aurez rédigé vos documents, merci d'inclure dans la description de la pull request les informations suivantes pour chaque fichier : "Qu'est-ce qui mène à ce document ? (Contexte, nécessité du document)" ; "Qui écrit ce document ? (Auteur, hiérarchie)" ; "Pourquoi doit-on écrire ce document ? (Raison, utilité)".
Ces questions permettent d'assurer la cohérence du lore. Une fois votre pull request soumise, attendez la confirmation d'un rédacteur.

Pour plus d'informations sur le Markdown utilisé et converti en HTML, cliquez ici.

Pour ajouter des images destinées aux illustrations, il vous suffit de créer un fork GitHub à partir de ce lien : ici.
Lorsque vous ajouterez une image à votre document, n'oubliez pas d'inclure son lien complet ainsi que la syntaxe Markdown correspondante.

Nous n'acceptons pas que les documents utilisent des liens externes comme illustrations. Seules les images provenant du dépôt d'images du studio sont autorisées.

Liste Markdown

  • Titre : # Texte (Pour les niveaux de titre, ajoutez un caractère "#".)
  • Gras : **Texte**
  • Italique : *Texte*
  • Liste : - Texte
